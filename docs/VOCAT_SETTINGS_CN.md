# ESP-VoCat v1.2 触屏设置与重新配网

工程：`D:\ESP32_XChatbot_v1.2`。开发分支：`feature/vocat-settings-wifi`。
适用固件：VoCat 的 Emote 表情界面版本。日期：2026-10-13。

## 使用方法

| 操作 | 效果 |
| --- | --- |
| 表情页从屏幕底部向上滑动后松手 | 打开设备设置 |
| 音量一行的 `−` / `+` | 每次调整 5，范围 0～100，立即生效 |
| 亮度一行的 `−` / `+` | 每次调整 5，范围 10～100，保存后下次开机沿用 |
| 设置页“返回”或向下滑动 | 回到表情页 |
| 设置页“重新配网” | 显示确认页；确认后结束当前对话并启动热点 |
| BOOT 键长按约 3 秒 | 直接进入配网，作为触屏不可用时的备用入口 |
| BOOT 短按 | 保留原来的开启/打断/结束对话操作；配网页面不触发录音测试 |

从底部约 60 像素内起滑、向上滑动至少约 60 像素，松手后打开菜单。
菜单内的触摸不会穿透到表情页触发对话开关。调整音量、亮度时对话仍可继续。
系统正在激活或升级时需等待完成后再重新配网。

**每次开机音量固定恢复为 50/100。** 运行中修改的音量会立即生效，但下次开机仍回到 50。
音量和亮度是不同设置；亮度保留上次保存值。

## 手机重新配网

1. 通过菜单确认配网，或在设备已正常启动后长按 BOOT。
2. 等待设备显示热点名和二维码。用手机系统相机扫描二维码加入设备热点；
   如果手机不支持 Wi-Fi 二维码，在手机 Wi-Fi 设置里手动选择屏幕上的热点。
3. 手机提示该热点“无互联网”时选择保持连接。
4. 若配网页面未自动弹出，用浏览器打开设备屏幕显示的地址（通常 `http://192.168.4.1`）。
5. 在网页选择目标 2.4 GHz Wi-Fi、输入密码并按网页提示保存/完成。
6. 设备退出热点、尝试联网，然后重新连接 ACOS。回到待唤醒后再说唤醒词开始新对话。

二维码仅用于加入设备热点，扫描动作不会直接完成家庭路由器的配网。
本次新增入口不清空已保存的 Wi-Fi 列表、ACOS 账号、token 或其他 NVS 数据。
网页使用原有 Wi-Fi 管理组件的验证/保存流程。

配网时点屏幕底部“取消配网”，设备停止热点并尝试已有 Wi-Fi 列表。
如果没有保存过任何网络，或已有网络不可用并连接超时，设备会再次进入配网。
取消操作不是恢复出厂设置，也不保证回到某一个指定 SSID。

### 本机预置多个 Wi-Fi

`.local/wifi.json` 可预置多组网络，适合不便用手机给自身热点配网的情况：

```json
{
  "networks": [
    { "ssid": "家庭网络名称", "password": "替换为实际密码" },
    { "ssid": "手机热点名称", "password": "替换为实际密码" }
  ]
}
```

仍兼容原来的单组 `ssid` / `password` 格式。总共最多预置 10 个不同的 SSID。
更改此文件需要重新编译并正常烧录；开机时加入 NVS 列表，不清空原有网络。
同名网络更新密码，凭据一致则不重复写入。设备列表满 10 组时，新增网络会替换末项。
预置网络若只在配网页面删除，下次启动仍会被固件重新加入；彻底取消预置需修改本文件并重新烧录。
手机配网页面添加网络则无需重新编译。所有热点需支持 2.4 GHz。
此文件已被 Git 忽略，真实密码不要写进公开源码或文档；编译后的固件含预置凭据。

## 实现位置与维护

- `main/boards/espressif/esp-vocat/esp_vocat.cc`：开机音量、触摸读取、BOOT 长短按、配网入口。
- `vocat_touch_policy.h` / `vocat_touch_checks.cc`：手势识别和编译期行为检查。
- `vocat_settings_display.*`：中文菜单、按钮区域、Wi-Fi 状态、热点二维码。
- `vocat_menu_font_20.c`：菜单专用中文小字库，首次联网前即可显示。
- `scripts/generate_vocat_menu_font.py`：更新菜单文案后重新生成字库；需要 Node.js/npx。
  字体来自 LVGL 附带的思源黑体，许可证在同目录 `vocat_menu_font_LICENSE.txt`。
- `main/boards/common/wifi_board.*`：按协议释放完成通知顺序进入配网，不依赖固定延迟。
- `main/application.*`：释放 ACOS 网络线程时保持主循环运行，完成后继续配网。

菜单直接使用现有 Emote/GFX 绘制任务和 LCD 回调，不另起第二套屏幕驱动。
资源重载前释放旧菜单对象；菜单对象复用，避免每次触摸重新分配整页。
普通 LVGL 显示配置不编入此触屏菜单，BOOT 配网入口仍有效。
