# 仓库精简范围与恢复方法

日期：2026-10-14。目标仓库：`Aesopppp/ESP32_XChatbot`。
默认分支：`dev/esp-vocat-v1.2`。当前目标硬件：ESP-VoCat v1.2 / ESP32-S3。

## 保留与移除

| 分类 | 处理及原因 |
| --- | --- |
| VoCat 板型、公共板级代码 | 保留硬件、菜单、配网和公共接口 |
| 应用、ACOS、音频、显示源码 | 保留，现有唤醒、打断、缓存、音量及时间同步逻辑不作修改 |
| 简体中文与英文资源 | 保留，英文是缺失提示音等内容的回退资源 |
| 其他板型及语言 | 移除，包括其他 S3 板型及 C3、C6、P4 等开发板配置 |
| 分区与芯片默认配置 | 保留通用默认配置、ESP32-S3 默认配置和 16 MB 分区表 |
| 构建与资源脚本 | 保留当前构建、唤醒模型、表情图标、菜单字体和配置生成流程 |
| 旧分区、旧板型示意图、独立音频/图片转换工具、Docker 目录 | 移除，当前构建流程不引用 |
| 测试与 GitHub Actions | 调整为当前 VoCat 范围，删除依赖已移除实物板型的矩阵测试，保留通用工具测试 |
| 私有配置、构建目录、下载的依赖 | 继续由 Git 忽略；原本就不在 GitHub 文件列表中 |

`main/CMakeLists.txt` 和 `main/Kconfig.projbuild` 同步收紧板型与语言选择，避免菜单继续选择不存在的文件。
板型只支持 VoCat，网络选项为 Wi-Fi。当前开发以 ESP-IDF 6.1 为准。

公共 codec、显示实现、MQTT/WebSocket、部分网络辅助代码和组件依赖清单仍有条件引用或共同编译关系，
本轮有意保留。不能只看到文件名像其他外设就直接删除；进一步删除需要独立调整接口、依赖和验证。
旧的通用协议、自定义板型文档作为架构参考保留，不表示本分支支持这些其他硬件或 ACOS 已支持小智 MCP。

这次是源码整理，不是运行时优化。其他板型原本就未选入 VoCat 固件，删除它们不会直接释放设备内存。
Git 历史完整保留，也不会通过强制推送清除旧历史；初次完整克隆大小可能仍受历史影响。

```powershell
cd D:\ESP32_XChatbot_v1.2
git fetch origin --tags
git worktree add --detach D:\XChatbot-before-trim backup/before-vocat-trim-20261014
```

目标目录须不存在。标签保存受 Git 管理的源码，不包含 `.local/`、下载组件、编译产物和设备 NVS。
这些本机文件未因本次精简而删除。旧代码需要单独准备本机配置才能编译使用。

- ESP-IDF 6.1：`idf.py build merge-bin` 成功，使用原工程有效缓存完成整个工程的资源打包、链接与分区检查。

- 实际编译的 71 个项目源文件与精简前相同；唤醒模型与播放图标哈希一致。

GitHub Actions 状态以对应提交的运行记录为准。成功构建不等同于真机音频验收。
